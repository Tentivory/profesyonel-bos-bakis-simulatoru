# Profesyonel Boş Bakış Simülatörü

## Giriş

Bu proje, insanlık tarihinin en büyük bilimsel atılımıdır. Boş boş bakma sanatını **tamamen bilimsel**, **aşırı ciddi** ve **hiçbir işe yaramayan** bir şekilde simüle eder. 

Artık toplantılarda, derslerde veya hayatın herhangi bir anında "neden boş boş bakıyorum?" diye sormayın. Cevabı bu kod bilir.

## Özellikler

- Rastgele iç çekmeler üretir.
- "Hayat anlamsız" seviyesinde dramatik mesajlar basar.
- Asla bitmez. Tıpkı gerçek hayattaki boş bakışlar gibi.
- %100 Türkçe. İngilizce kullanmak yasaktır, çünkü boş bakmak evrenseldir ama biz daha iyisini yaparız.

## Kurulum

```bash
python bos_bakis.py
```
